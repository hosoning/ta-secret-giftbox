# 《TA 的秘密礼盒》

面向中国内地梦女的「用户 × 梦角」数字拆礼物沉浸式互动网站。

**定位**：象征性数字礼物 + 私人留言，本地收藏。不是剧情游戏、任务系统或盲盒抽奖。

- 简体中文 · 手机优先 · 无需注册 · 可独立部署出售
- 所有第三人称统一使用「TA」
- 静态站点，无后端、无账号、无内购

---

## 功能一览

| 模块 | 说明 |
|------|------|
| 封面 | 精美礼盒视觉 +「拆开 TA 为你准备的小惊喜」 |
| 名字 | 填写双方名字，可修改，仅存本机 |
| 心情 | 7 种场景/心情筛选礼物池 |
| 拆礼 | 可跳过的拆丝带/开盖动画 |
| 揭示 | 礼物图标 → 卡片标题 → 完整留言 → 可选小纸条（语义绑定） |
| 陈列室 | IndexedDB 完整历史，搜索、收藏、删除、清空 |
| 备份 | JSON 导出 / 导入恢复 |
| 分享 | Canvas 生成可保存的分享图 |
| 提示 | 明确本地存储风险与「数字象征性」声明 |

---

## 内容规格（首版已满足）

- **40 种**有清晰象征含义的礼物
- 每种 **3 套**人工编写的完整内容包
- 合计 **120 套**（礼物 ID + 名称 + 类别 + 适用心情 + 卡片标题 + 完整留言 + 寓意标签 + 视觉引用）
- **绑定抽取**：先按心情过滤礼物池，再从该礼物的 packs 中取一套，绝不随机礼物 + 随机无关留言
- 近期重复优先降低（localStorage 记录最近 giftId）
- 表达风格覆盖：温柔 / 克制 / 直接 / 俏皮 / 安静

内容文件：`js/data.js`

---

## 技术栈

- 纯静态：HTML + CSS + 原生 JavaScript
- 存储：IndexedDB（礼物历史）+ localStorage（偏好与近期记录）
- 无框架、无构建、无后端、无付费 AI
- 可直接用任意静态服务器或双击 `index.html` 打开（部分浏览器对 file:// 下 IndexedDB 有限制，建议本地起服务）

---

## 本地运行

```bash
# 进入目录
cd ta-secret-giftbox

# 任意静态服务器，例如：
npx serve .
# 或
python3 -m http.server 8080
```

浏览器打开提示的地址即可。手机可用同局域网 IP 访问测试。

## 部署

任意静态托管均可：

- GitHub Pages / Cloudflare Pages / Netlify / Vercel
- 国内：对象存储静态网站、虚拟主机、自己的 Nginx

只需上传整个目录，保证 `index.html` 为入口。无需 Node、无需环境变量。

内容与素材可独立更新：替换 `js/data.js` 或 `assets/` 后重新部署即可。

## 验收测试清单

### 内容与抽取
- [ ] 礼物种类 ≥ 40
- [ ] 完整内容包 ≥ 120
- [ ] 同一心情多次拆礼，礼物与留言始终语义一致（不出现「电影票 + 围巾文案」这类冲突）
- [ ] 近期拆过的礼物出现频率明显降低，但不承诺永不重复

### 流程
- [ ] 封面 → 名字 → 心情 → 拆礼动画 → 分层揭示 完整可走通
- [ ] 拆礼动画可点击跳过
- [ ] 名字可修改并记住（刷新后仍在）
- [ ] 「再拆一盒」回到心情选择，历史不被覆盖

### 陈列室
- [ ] 每次拆礼自动写入，陈列室按时间倒序展示
- [ ] 搜索（名称/留言/心情）有效
- [ ] 收藏 / 取消收藏
- [ ] 点击条目可完整重看，内容不变
- [ ] 单条删除有确认
- [ ] 清空全部有确认
- [ ] 导出 JSON 后，清空再导入，记录恢复

### 分享与声明
- [ ] 生成分享图可下载，含礼物名、留言、双方名字
- [ ] 封面与陈列室有「数字象征性、不涉及真实寄送」提示
- [ ] 有本地存储丢失风险说明

### 体验
- [ ] 手机竖屏单手可完成主要操作
- [ ] 视觉为墨绿 × 柔金基调，拆礼有仪式感
- [ ] 无注册、无付费墙、无概率诱导文案
